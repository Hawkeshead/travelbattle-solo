# Assets

Where the pictures and sounds in this game came from.

This is a personal project — a digital version of a board game Matt owns, made
for him and a couple of friends to play. It isn't sold and isn't offered as a
product, so this file is a record of where things came from, not a legal
clearance exercise.

## Sounds

| Files | Source | Licence |
|---|---|---|
| `audio/ui/click1.wav`, `click4.wav`, `switch12.wav`, `switch14.wav` | [Kenney](https://kenney.nl) UI Audio Pack | CC0 1.0 (public domain) |

CC0 means Kenney gave these away with no conditions attached — nothing is
required in return. `AUDIO_CREDITS.txt` has the detail, including what's still
to be sourced.

Some sound libraries do ask for a credit line in exchange (CC-BY ones do). If a
future sound comes from one of those, add a line for it in `AUDIO_CREDITS.txt`
at the same time you add the file, so the record doesn't drift.

## Pictures

- `assets/portraits/` — 24 regiment portraits, carried across from the
  TravelBattle Hub archive. See the note at `js/render-units.js:30`.
- `assets/brigadiers/` — 6 commander portraits: Wellington, Uxbridge,
  Thomas Graham, Napoleon, Soult, Murat.
- `assets/icons/` — 2 cannon icons.

No original source was recorded for any of these. Most are likely period
paintings, which are long out of copyright; some may be modern uniform
illustrations, which aren't. The files themselves don't say which is which.

For a game a few people play on their phones, that's fine and nothing needs
doing. It would only be worth sorting out if the game were ever put in front of
a wider audience or turned into something offered publicly — in which case the
images are the first thing to look at.

## The board game

The rules come from
[TravelBattle](https://boardgamegeek.com/boardgame/228509/travelbattle), which
Matt owns, merged with its advanced rule set. Game rules and mechanics aren't
copyrightable, so a home-made digital version of a game you already own is
ordinary personal use. This project doesn't reproduce the rulebook text.
